COMO PUBLICAR NO GITHUB PAGES
1. Criar um repositório no GitHub, por exemplo: simulador-imobiliario.
2. Carregar TODOS os ficheiros deste ZIP para a raiz do repositório.
3. Abrir Settings > Pages.
4. Em Build and deployment, escolher Deploy from a branch.
5. Selecionar branch main e pasta /root.
6. Guardar. O GitHub criará um endereço público HTTPS.

COMO INSTALAR NO ANDROID
1. Abrir o endereço da aplicação no Chrome.
2. Menu ⋮ > Adicionar ao ecrã principal / Instalar aplicação.
3. A aplicação passa a abrir em modo autónomo, como uma app.

COMO INSTALAR NO IPHONE
1. Abrir o endereço no Safari.
2. Tocar em Partilhar.
3. Escolher Adicionar ao ecrã principal.

A app funciona offline depois da primeira abertura e guarda comissão, IVA e margem no telemóvel.
